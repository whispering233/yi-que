# 配置说明

## 配置原则

工具站阶段是**纯静态应用**，没有运行时配置——所有差异在构建期确定。因此：

- **不使用运行时环境变量开关**。需要区分的行为一律通过构建期配置或数据源切换实现
- **不把配置散落在代码中**。可调项集中定义，且必须能回答「改它会影响什么」
- 涉及用户体验的默认值（如默认韵书）是**产品决策**，不是配置项

## 构建期配置

| 配置项 | 作用 | 默认 |
| :--- | :--- | :--- |
| 站点根 URL | 生成规范链接、站点地图、结构化数据中的绝对地址 | 必须显式指定 |
| 站点名称与描述 | 页面元数据 | — |
| 源码仓库地址 | AGPL-3.0 要求的源码入口链接 | 必须显式指定 |
| 数据源版本 | 锁定上游语料的版本或提交，保证构建可复现 | 锁定到具体版本 |
| 产物体积预算 | 护栏自检的上限（见 `build.md`） | 按预算表 |
| 数据源许可标注文本 | 站点显著位置的第三方来源与许可声明 | 必须显式指定 |

## 应用级默认值

这些值影响用户看到的结果，属产品决策，集中定义以便整体评审。

| 项 | 说明 |
| :--- | :--- |
| 默认韵书 | 用户首次进入时使用的韵书 |
| 默认展示词格 | 一个词牌有多个词格时默认选中哪个（通常为正体） |
| 检索结果条数 | 单页展示量 |
| 判定态呈现 | 合 / 出律 / 待定三态的名称与视觉语义，须与 `../ui/DESIGN.md` 一致 |

## 数据管道参数

| 项 | 作用 | 说明 |
| :--- | :--- | :--- |
| 归一化阈值 | 词牌名命中率的下限 | 跌破即构建失败 |
| 异常字符白名单 | 允许出现的非汉字字符 | 只增不减；新增须有明确理由 |
| slug 人工指定表 | 解决多音字冲突 | 冲突未解决时构建失败 |
| 字体源 | 生成 fallback 子集所用的源字体 | 须为许可允许嵌入的开源字体 |
| 需保留字符集 | fallback 子集须包含的字符范围 | 扩展区汉字 + 词谱符号 + 生僻标点 |

## 响应式断点

断点定义是**唯一来源**，位于 `src/ui/tokens.ts` 的 `BREAKPOINTS`。具体值与含义见 `30-web-app.md`。

**两侧消费方式不同，因为 antd 无法派生：**

| 消费方 | 方式 |
| :--- | :--- |
| Tailwind | `globals.css` 的 `@theme` 镜像；一致性由护栏测试断言 |
| JS 侧断点判断 | `useBreakpoint`，直接消费该常量 |
| **antd 响应式 API** | **禁用**——其断点硬编码为 576/768/992/1200，无法通过 token 覆盖 |

**禁止在任何地方重新定义断点数值。** 两套断点必然漂移，表现为某些宽度下布局与 JS 判定不一致。

## 设计令牌

设计令牌的**唯一来源是 antd 的 token 体系**，文档镜像为 `../ui/DESIGN.md`。

**禁止在组件中写具体色值与字号**。需要新令牌时先在 `DESIGN.md` 中定义，再在代码中引用。

## 社区阶段（B）的配置

进入社区阶段后新增服务端配置（数据库连接、会话密钥、邮件、上传存储等）。**该阶段的配置方案在实施前单独设计**，本文不预先规定。

原则不变：不把密钥写入版本控制，配置项集中定义且有明确作用域。
