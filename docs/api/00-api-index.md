# API 接口索引

## 当前状态：无服务端 API

工具站阶段是**纯静态应用**，没有服务端，因此没有 API。

全部能力由浏览器内的纯函数层提供：

| 能力 | 实现层 | 说明 |
| :--- | :--- | :--- |
| 格律校验（对谱、韵位、多音字消歧、变格、辨谱） | 格律引擎 | 纯函数，输入词牌与文本，输出逐字判定 |
| 韵书查询（平仄、韵部） | 格律引擎 | 纯函数 |
| 词库检索 | 客户端索引 | 语料加载后在本机建索引并检索 |
| 词作 / 词牌 / 词人数据 | 静态产物 | 构建期生成，页面预渲染 |

设计见 `../design/10-prosody-engine.md` 与 `../design/30-web-app.md`。

## 为什么不做服务端 API

格律校验的核心体验是**逐字实时反馈**。服务端化意味着每次校验一次网络往返，直接损失核心体验，而收益为零——《钦定词谱》是公有领域的，词谱数据不存在可保护性。

同理，词库检索在客户端完成：语料 Brotli 后 2.08MB，浏览器运行时建索引仅需数百毫秒，之后检索零延迟且离线可用。
