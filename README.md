# 一阕

宋词的创作、鉴赏与交流平台。

## 这是什么

一阕把宋词的格律校验做成**纯客户端的纯函数**：输入即校验、逐字即反馈。

同类平台的格律校验都需要提交表单后等待服务端返回，且逻辑是闭源黑盒。而词谱是**公有领域文献**——《钦定词谱》成书于清康熙五十四年（1715）——服务端化不带来任何护城河，只带来延迟。本项目据此把引擎整体放在浏览器内，并让引擎与数据完全开放。

## 特色

| 特色 | 说明 |
| :--- | :--- |
| **逐字实时校验** | 格律引擎全部在浏览器内运行，无网络往返 |
| **双韵书** | 词林正韵与中华新韵，均为本项目自建，归并规则白盒可核验 |
| **完整词谱** | 据《钦定词谱》整理，818 调 / 2475 体，覆盖全宋词 96.6% 的词作 |
| **全库离线检索** | 全宋词两万余首，索引在浏览器内建立，检索离线可用 |
| **零服务端** | 纯静态站点，无数据库、无 API、无运维 |
| **引擎与数据全开放** | AGPL-3.0 |

## 技术栈

| 层 | 选型 |
| :--- | :--- |
| 语言 | TypeScript |
| 框架 | Next.js（App Router，静态导出） |
| UI 组件 | antd v6 |
| 样式 | Tailwind CSS（**只管布局**，颜色与排版走 antd token） |
| 数据 | 构建期由数据管道生成的静态产物 |
| 检索 | 客户端运行时索引 |

后端（PostgreSQL + Drizzle）属于后续的社区阶段，当前不引入。

字体策略：**不下载全量中文字体**，用平台原生宋体栈 + 40KB 的扩展区 fallback 子集。

## 数据来源

| 用途 | 来源 | 许可 |
| :--- | :--- | :--- |
| 词谱 | 《钦定词谱》（清·王奕清等奉敕纂修，1715） | 公有领域 |
| 词作文本 | 全宋词开源整理版（持续校勘修订） | MIT |
| 拼音 | Unicode Unihan `kMandarin` 派生的拼音表 | MIT |
| 韵书 | 《词林正韵》（清·戈载） | 公有领域 |

词谱以公有领域原典为基线，**不依赖来源存疑的第三方衍生数据**。数据源的完整调研与实测证据见 `docs/research/competitive-analysis.md`。
